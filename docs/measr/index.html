A pixel ruler that reads the screen. It finds the edges itself, so moving the pointer tells you the space you're in and a loose drag closes in on what you meant. For checking a UI, or telling an AI exactly what to change.

02 what it does

it reads the pixels. so you never have to line up a ruler.

>edges, found for you

Lines run out from the pointer to the nearest edge each way. The space you're in, as you move: 16 × 48.

>boxes that close in

Drag a box loosely round something and it snaps to what's inside. alt+drag keeps it exactly as drawn.

>elements in a click

Double-click and measr boxes the element under the pointer: a button's fill, a card's inside.

>gaps and padding

Two boxes give you the gap between them, or the padding when one sits inside the other.

>copy it your way

Plain (240 × 48), css (width: 240px; …) or tailwind (w-60 h-12). s copies an image with the measures drawn on.

>true pixels

Worked out on the screenshot's own pixels, in css px or screen px. A line is always exactly one screen pixel.

04 the details

  • edges, tuned

    exact (any change), soft (ignores compression noise and soft shadows; the default) or loose (only strong lines).

  • units

    css px (screen pixels ÷ the display's scale, what you write in code; the default) or screen px. On a 100% display they're the same.

  • a pointer you can see on anything

    Your pointer is hidden while you measure. The crosshair sits on the exact pixel, with a dark halo, so it reads on light and dark screens alike.

  • ready at once

    One hidden overlay per display is kept warm, so the key opens instantly. Measures aren't saved: they're gone when measr closes.
