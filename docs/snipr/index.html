02 what it does

nothing on screen until you ask. then the snip, right where you took it.

>on the clipboard at once

Release the mouse and the snip is already copied. Paste it anywhere, or keep going.

>lifts off the screen

The snip opens in a small ghost window exactly where you took it. Hover for the chrome; at rest it's just the image.

>mark it up

Pen, arrow, box, circle, text and blur, each on one shortcut. Shift snaps arrows to 45° and makes boxes square.

>blur for good

Nothing of what's under a blur survives: one average colour plus secure random noise. The unblurred copy on the clipboard is replaced too.

>copy the text

alt+shift+t drags out text instead of an image, with Windows' own OCR. Rows, columns and indentation kept.

>drag it out

Grab the image and drop it in a chat, a folder or a document. Or ctrl+s to save it to Pictures\snipr.

04 the details

  • instant

    One hidden overlay per display is kept ready, so the shortcut opens a snip at once. It's snipr's only cost while it waits.

  • inks and fonts

    Marks in ghost (white with a dark halo, reads on anything), red or black. Text in JetBrains Mono, IBM Plex Mono, DM Mono, Martian Mono, Space Mono or VT323, or a system font.

  • settings

    Auto copy, auto open, auto save, close after copy, the folder, a matte border, keep snips on top, ask before discard. Tray → snipr → settings, or the gear on any snip.

  • private

    Copy text uses the OCR built into Windows 10 and 11. Nothing is uploaded, ever: snips go to your clipboard and, if you want, to Pictures\snipr.

  • platforms

    Made on Windows. On macOS it needs screen recording permission; on Linux it works on X11, and Wayland asks each time. Snip text is Windows only.
