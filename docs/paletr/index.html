02 what it does

the exact pixel, not a guess. read from the screen itself.

>a loupe, not a guess

The pointer becomes a square loupe: the pixels round it, magnified, with the one in the middle ringed.

>three formats

#1e90ff, rgb(30, 144, 255) or hsl(210, 100%, 56%). tab switches, and it's remembered.

>a palette that remembers

The last 30 colors you picked, newest first. Click one to copy it again; the same color twice moves to the front.

>full color

Nothing is dimmed while you pick, because you're judging colors. One frozen overlay per display.

>exact on any display

Read from the screen grab in its own pixels, so on a scaled display you get the pixel you pointed at, not a blend.

>pick a few in a row

shift+click copies and keeps picking. A click acts on release, so nothing reaches the app underneath.

04 the details

  • nothing runs until you pick

    Its start reads one small file and registers the key. The overlays are made on the first pick, stay warm for ten minutes, then close: an idle paletr has no windows at all.

  • the palette

    Tray → paletr → palette. Square swatches; right-click to copy as another format or remove one. p picks another.

  • data

    %APPDATA%\utilr\tools\paletr\paletr.json: the key, the format, the palette. It stays put through updates.

  • macOS

    Picking needs screen recording permission for utilr.
